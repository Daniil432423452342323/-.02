## Инструкция по запуску проекта

Для запуска модулей на Windows используйте стандартный лаунчер `py` в терминале:

1. **Инициализация и наполнение базы данных:**
   ```bash
   py db_tasks.py
   ```
2. **Запуск графического интерфейса менеджера задач:**
   ```bash
   py task_manager_gui.py
   ```

## Шпаргалка на фсякий случай (Краткая архитектура)

* **База данных:** Данные хранятся в реляционной БД **SQLite** (`databases/db_variant_1.db`) в таблице `app_tasks`.
* **Интерфейс:** Графическое окно спроектировано на базе библиотеки **Tkinter** с использованием динамического списка карточек на элементе `Canvas` с прокруткой (`Scrollbar`).
* **Логика автоматизации:** Приложение автоматически считывает приоритет и статус задач. Задачи с высоким приоритетом автоматически подсвечиваются цветом `#ff8080`. При нажатии кнопки «Завершить» статус в БД меняется на «Выполнена», а карточка становится серой.
